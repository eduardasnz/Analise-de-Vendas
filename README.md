# 🐍 Automação de Relatórios com Python

Meu primeiro projeto utilizando Python! 

O projeto consiste em automatizar a análise de um relatório de vendas e o envio dos resultados por e-mail.

### 🛠️ Tecnologias utilizadas
- Python
- Pandas
- PyAutoGUI
- Pyperclip
- OpenPyXL

### ⚙️ Funcionalidades
- Acessar e baixar uma planilha de vendas.
- Analisar os dados utilizando Pandas.
- Calcular o faturamento e a quantidade de produtos vendidos.
- Enviar os resultados automaticamente por e-mail.

### 📚 Objetivo
Praticar Python, automação de tarefas e análise de dados por meio de um problema prático.
